# Privacy & Data Sovereignty Charter

## Principles

SolluPath is designed for vulnerable communication moments—often inside intensive care units, emergency wards, public transit, or intimate caregiving contexts. Privacy is treated as an ethical imperative.

## Guarantees

1. **No Account or Authentication Required**:
   - The application does not require sign-up, email, phone number, or profile creation.
   - Any person can open SolluPath and communicate immediately in under 3 seconds.

2. **100% On-Device Local Storage**:
   - Composed draft sentences, favorite phrases, custom phrases, and accessibility preferences remain in the user's browser `localStorage` or memory.
   - No data is synchronized to a remote server or telemetry backend.

3. **Zero Third-Party Trackers**:
   - Zero advertising scripts, Google Analytics, cookies, or marketing trackers.
   - No fingerprinting or device telemetry.

4. **Transparent Machine Translation Boundary**:
   - Core AAC functions rely strictly on bundled, human-curated phrase dictionaries.
   - The application does not transmit health or distress messages to unverified third-party cloud translation engines by default.
   - If future optional cloud translation APIs are enabled, they will mandate explicit, turn-by-turn user consent before text transmission.

5. **User Data Deletion**:
   - A one-click "Clear All Local App Data & Preferences" button is provided in Accessibility Settings.
   - Instantly wipes all stored local phrases and resets the application to factory default state.
